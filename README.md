# Heroplan 英雄资料库 🐉

**语言(Language):** [English](./README_EN.md) | **中文**

**在线访问:** [https://heroplan.github.io](https://heroplan.github.io)

## 🚀 项目简介

**Heroplan** 是专为《帝国与谜题》(Empires & Puzzles) 玩家打造的一站式英雄资料与攻略平台。
纯静态前端实现，无需后端，打开浏览器即可使用。

它的核心能力可以概括为四件事：

1. **游戏内全语言英雄资料查询** —— 完整支持游戏内的 **20 种语言**；
2. **全英雄立绘展示** —— 静态高清立绘 + 游戏内动态立绘动画；
3. **当前版本未来英雄预览** —— 按官方发布日期列出尚未上线的英雄；
4. **一整套玩家工具箱** —— 属性计算器、抽奖 / 队伍 / 聊天模拟器、材料出处、通缉任务、活动日历、兑换码等。

全部英雄数据由 **Juno** 制作：直接解析游戏**官方配置文件**生成，不依赖第三方数据源。

---

## ✨ 主要功能

### 1. 游戏内全语言英雄资料查询（20 种语言）

支持 **简体中文、繁體中文、English、日本語、한국어、Français、Deutsch、Español、Português、Italiano、Русский、العربية、Türkçe、Polski、Nederlands、Svenska、Dansk、Norsk、Suomi、Indonesia**。

切换语言后，**英雄名称、特殊技能、被动技能、家族与来源**全部按该语言呈现（含阿拉伯语的 RTL 从右向左排版）。
每位英雄都提供：

* 星级、元素、法速、职业、家族、起源、服装；
* **80 级 / LB1 / LB2** 三档的**攻击、防御、生命、战力**。

所有英雄数据均由**官方配置文件**解析得出。

### 2. 全英雄立绘展示

* **静态立绘**：英雄详情页可查看高清立绘；
* **动态立绘**：对支持的角色播放游戏内的精灵动画立绘。

### 3. 当前版本未来英雄预览

* 按官方 `发布日期` 展示**尚未上线**的英雄，方便提前规划资源与抽卡预算；
* 未来英雄**照常展示与查看**，但**收藏功能会锁定到该英雄正式发布时**（避免把未上线英雄计入收藏规划）。

### 4. 英雄数据库与高级检索

* **多维筛选**：名称、星级、元素、法速、职业、家族、起源、服装等；
* **高级技能搜索**：可对 **特殊技能文本**、**被动技能文本**、**技能分类标签**做复合查询，支持 `与 / 或 / 非` 逻辑；
* **属性筛选**：按战力、攻击、防御、生命设定下限查找；
* **一键事件筛选**：内置「一键满级」与「购买服装」活动日期，一键筛出符合条件的英雄或服装；
* **收藏夹**：收藏英雄组合，并通过链接一键分享给盟友；支持导出 / 导入配置。

### 5. 属性计算器

实时换算不同**极限突破（LB1 / LB2）**、**天赋（+20 / +25）**与**服装奖励**档位下的确切攻击、防御、生命与战力，
并支持设定**天赋优先级**（攻 / 防 / 血的不同加点顺序）。另有**职业天赋树**视图。

### 6. 玩家工具箱

| 工具 | 说明 |
|---|---|
| **抽奖模拟器** | 复现卡池概率与召唤记录，查看概率详情与召唤历史 |
| **队伍模拟器** | 搭配阵容、保存队伍并分享给盟友 |
| **聊天模拟器** | 制作带自定义颜色与游戏表情的聊天文本，一键复制 |
| **材料出处指南** | 升阶 / 锻造材料的最佳掉落关卡一览（桌面悬浮高亮、移动端点击高亮） |
| **通缉任务表** | 各系通缉宝箱（红 / 绿 / 蓝 / 紫 / 黄）在 S1–S6 的最佳速刷关卡 |
| **活动日历** | 查看当前活动与时间安排 |
| **兑换码** | 汇总当前可用兑换码 |
| **关卡指南** | 关卡掉落与产出速查 |

### 7. 其他

* **多语言与主题**：20 种语言一键切换；日间 / 夜间双主题；
* **轻量高效**：纯前端实现，加载快、资源占用低，适配桌面与移动端。
